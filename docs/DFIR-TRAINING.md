# DFIR Training Guide

## Objective

This document describes the forensic investigation of the educational ransomware simulation.

The exercise is designed to reproduce ransomware-like indicators without performing destructive actions.

## Evidence Sources

The investigator should consider collecting:

- Process information.
- Process command line.
- Process creation timestamps.
- File creation timestamps.
- File modification timestamps.
- Network connection information.
- Local server logs.
- Windows event logs.
- Endpoint telemetry.
- Relevant artifacts generated by the simulator.

## Timeline

Build a timeline containing:

1. Simulator execution.
2. Creation of training files.
3. Simulated encryption phase.
4. Connection to the local server.
5. Start of the countdown.
6. Analyst investigation.
7. RSA key recovery.
8. Successful unlock.

## File Analysis

The investigator should verify whether the training files were actually modified.

Expected result:

The files are harmless training files and no real encryption should occur.

## Network Analysis

Investigate connections to:

127.0.0.1:8080

Determine:

- Which process initiated the connection.
- When the connection occurred.
- Which HTTP requests were generated.
- What information was returned by the server.

## Process Analysis

Determine:

- Process name.
- Process path.
- Command line.
- Parent process.
- Process creation time.
- Child processes.
- Network activity.

## Persistence Analysis

Verify that the simulator does not create:

- Scheduled tasks.
- Services.
- Registry Run keys.
- Startup entries.
- WMI persistence.

## Incident Conclusion

The final report should explain:

- What happened.
- Which process generated the activity.
- Which files were involved.
- Which network endpoint was contacted.
- Whether encryption actually occurred.
- Whether data was destroyed.
- How the RSA challenge was solved.
- What containment actions would normally be appropriate.

## Training Outcome

The investigator should be able to distinguish between:

1. Ransomware-like behavior.
2. Actual file encryption.
3. Simulated encryption.
4. Destructive behavior.
5. Non-destructive laboratory activity.
